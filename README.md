# RAG-Based Answer Sheet Evaluator
An AI-powered answer evaluation system that uses Retrieval-Augmented Generation (RAG) and language models to evaluate student answers against reference material.

## Features
- Evaluates student answers using reference
- Checks whether key concepts are correctly addressed
- Identifies missing or incorrect concepts
- Provides rubric-based scoring
- Generates constructive feedback
- Uses an LLM for semantic evaluation rather than simple keyword matching

## Goal
The goal of this project is to automate and improve the evaluation of descriptive student answers while providing meaningful feedback on their understanding.

## Tech Stack
- Python
- Hugging Face Transformers
- Large Language Model (LLM)
- Retrieval-Augmented Generation (RAG)
- Kaggle Notebooks
